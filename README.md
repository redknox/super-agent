## Fibonacci

`fibonacci(n)` returns the *n*-th Fibonacci number, 1-indexed, so
`fibonacci(1) == 1`, `fibonacci(2) == 1` and `fibonacci(3) == 2`.

```python
from fibonacci import fibonacci

fibonacci(10)  # 55
```

